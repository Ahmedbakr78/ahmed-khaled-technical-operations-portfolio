# Support

## Getting Help

This is a personal portfolio project, but the engineering documentation is maintained for reviewers, collaborators and future maintenance.

### Before opening an issue

1. Read the [README](README.md).
2. Check the [FAQ](docs/FAQ.md).
3. Review the [Architecture](ARCHITECTURE.md) and [Deployment](docs/DEPLOYMENT.md) documentation.
4. Search existing issues.
5. Reproduce the problem on the latest `main` branch.

### Where to ask

| Topic | Channel |
|:---|:---|
| Bug report | GitHub issue using the bug template |
| Feature request | GitHub issue using the feature template |
| Security vulnerability | Private advisory; see [SECURITY.md](SECURITY.md) |
| Accessibility issue | GitHub issue with the `accessibility` label |
| Professional inquiry | Contact form or direct email in the portfolio |

### What to include

- A clear summary.
- Steps to reproduce.
- Browser, operating system and viewport.
- Console output or screenshots.
- Whether the issue occurs in both themes.
- Whether the minimal 3D preset changes the result.

---

## Response Expectations

This is a personal project. Issues are reviewed on a best-effort basis. Security reports are prioritised. Please be patient and respectful.
